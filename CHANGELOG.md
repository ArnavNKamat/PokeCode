# Change Log

All notable changes to the "poke-code" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

These version entries are retrospective development milestones based on the Git commit history; they do not imply that these versions were published.

## [1.0.0] - Unreleased (current development version)

- Added transparent, blue-tinted trophy icons to achievements.
- Added default species height, weight, gender probability, and encounter-rate details to seen Pokédex entries.
- Changed eggs to become ready to hatch after the required encounters; players now click a ready egg to hatch it and choose its name.
- Added sorting across all unlocked Boxes or only the current Box by Pokédex number, catch order, or primary-type groups.
- Improved Box navigation and keyboard interaction, escaped player nicknames in Box UI, and corrected max catch-rate behavior so ordinary Poké Balls do not guarantee a catch.

## [0.9.0] - 2026-10-08 (development milestone; published status not implied)

- Added offline, species-specific gender, size, and hatch-cycle data; caught and bred Pokémon retain individual details.
- Added same-species breeding, egg storage, encounter-based hatching, and hover/focus box actions.
- Improved Box action menus with larger vertical controls, added Pokémon details, and required explicit Yes/No breeding confirmation.
- Changed Box actions to a click-opened menu that dynamically positions around the selected slot, and added a nickname prompt when an egg hatches.
- Highlighted achievements that unlock Boxes and added explicit reward labels to their cards.
- Added a startup confirmation after detecting an extension version change; VS Code remains responsible for installing updates.

## [0.8.0] - 2026-10-08 (development milestone; not published)

- Added General and Kanto achievement pages, new achievement milestones, and a complete Pokédex achievement.
- Changed storage to 20 Pokémon per box, starting with one box and unlocking up to 12 boxes through achievements and Pokédex completion.
- Added a future-plans section and invited community suggestions and bug reports in the README.

## [0.7.0] - 2026-10-05 (development milestone; not published)

- Added catch, collection, Legendary, and Mythical achievements.
- Added achievement unlock announcements and a credits screen.
- Refined navigation icons and added extension tests for collection and achievement behavior.

## [0.6.0] - 2026-10-05 (development milestone; not published)

- Added all 151 Kanto Pokémon and their bundled sprites.
- Added Generation I-inspired catch mechanics, nicknames, and improvements to box navigation and organization.

## [0.5.0] - 2026-10-01 (development milestone; not published)

- Added the Activity Bar experience, five collection boxes, Pokédex, and collection management.
- Added Pokémon sprites and the PokeCode extension branding.

## [0.4.0] - 2026-10-01 (development milestone; not published)

- Added starter Pokémon, weighted encounters, saved progress, and reset support.
- Added Pokédex and box views.

## [0.3.0] - 2026-09-28 (development milestone; not published)

- Added starter selection, wild encounters, catch attempts, and persistent game state.

## [0.2.0] - 2026-09-27 (development milestone; not published)

- Added the initial Pokémon roster and a basic encounter-and-catch experience.

## [0.1.0] - 2026-09-27 (development milestone; not published)

- Set up the extension project, VS Code development launch configuration, and test tooling.
